# Backend Rules

## Tech Stack
- Python 3.11, FastAPI 0.110+, Pydantic v2, uvicorn
- Testing: pytest + pytest-asyncio + httpx
- Linting: ruff
- Type checking: mypy
- Security: pip-audit

## Commands
```bash
# Validate all (run before commit)
python scripts/pre_commit_validate.py

# Tests
pytest tests/ -v

# Lint
ruff check src/ tests/

# Format
ruff format src/ tests/

# Type check
mypy src/ --ignore-missing-imports

# Security
pip-audit --desc
```

## Code Standards
- Type hints on ALL public functions
- Pydantic models for all request/response
- Use `from __future__ import annotations`
- No wildcard imports
- Test all error paths

## Architecture
- `src/app.py` — FastAPI app + routes
- `src/models.py` — Pydantic models
- `src/store.py` — In-memory URL store (implements BaseStore interface)
- `src/config.py` — Environment-based configuration
